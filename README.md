## Public-information boundary

This repository intentionally contains only career-safe material. The Textent
page uses a synthetic scenario and a conceptual reference architecture. It does
not contain private source code, repository internals, prompts, credentials,
AWS identifiers, customer documents, employer data, production topology, or
measured product-performance claims.

The private Textent implementation, infrastructure, and development records
remain in separate private repositories.

## Deployment

The site is published through GitHub Pages from the public
`aravind-bit/aravind-bit.github.io` repository. No application backend,
database, model endpoint, upload flow, or user account is exposed by this site.
