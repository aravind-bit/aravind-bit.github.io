CREATOR & PRODUCT ARCHITECT

Textent — Decisions You Can Defend

Textent is designed for large, versioned document sets where structure, evidence, and prior decisions must survive every review. It turns the work into a bounded set of consequential findings: what changed, why it matters, what needs attention, and what was ultimately decided.

I created the product direction, designed the target architecture, and led implementation through reviewed GitHub pull requests and automated verification. The case study separates the working core from the enterprise roadmap so every claim is easy to inspect.

Explore the Textent.ai architecture case study →
Structured extraction DOCX structure becomes stable evidence anchors instead of an indiscriminate text dump.
Bounded AI assignment The designed model stage receives admitted candidates and compact evidence—not an uncontrolled document dump.
Fail-closed validation Schema, evidence IDs, quotations, and allowed claims are checked before display.
Event-driven scale design Direct intake, queue backpressure, workflow state, recovery, deletion, and content-free telemetry are specified as operating contracts.
